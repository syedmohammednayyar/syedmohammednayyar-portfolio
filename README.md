# Syed Mohammed Nayyar's Portfolio
[![Ask DeepWiki](https://devin.ai/assets/askdeepwiki.png)](https://deepwiki.com/syedmohammednayyar/syedmohammednayyar-portfolio)

This repository contains the source code for my personal portfolio website. It is a fully responsive, single-page site built with HTML, CSS, and vanilla JavaScript to showcase my skills, projects, qualifications, and contact information.

## Features

*   **Dynamic Hero Section:** An engaging "typed text" animation introduces my roles as a Software and Web Developer.
*   **Responsive Design:** The layout seamlessly adapts to all device sizes, from mobile phones to desktop screens.
*   **Interactive Project Gallery:** A visually appealing card-based gallery showcases my projects. Clicking on any card navigates to my GitHub repositories page.
*   **Smooth Scrolling Navigation:** A sticky navigation bar with a mobile-friendly hamburger menu allows for easy navigation between sections.
*   **Functional Contact Form:** A "Get In Touch" section features a working contact form that submits data to a Google Sheet using the SheetDB API.
*   **Downloadable Resume:** A prominent button allows visitors to download my resume directly.
*   **Comprehensive Sections:**
    *   **About Me:** A detailed introduction, contact details, and links to my social media profiles (Instagram, LinkedIn, GitHub).
    *   **My Skills:** A grid highlighting my technical competencies including the MERN stack.
    *   **Qualifications:** A timeline of my educational background.

## Technologies Used

*   **Frontend:** HTML5, CSS3, JavaScript
*   **Icons:** [Font Awesome](https://fontawesome.com/)
*   **Form Backend:** [SheetDB](https://sheetdb.io/)

## Getting Started

To run this project locally, follow these steps:

1.  Clone the repository to your local machine:
    ```bash
    git clone https://github.com/syedmohammednayyar/syedmohammednayyar-portfolio.git
    ```

2.  Navigate to the project directory:
    ```bash
    cd syedmohammednayyar-portfolio
    ```

3.  Open the `index.html` file in your preferred web browser. No special build steps or dependencies are required.
